## Brand & Style

This design system embodies clarity, intellectual rigor, and mechanical precision. Built for an enterprise-grade PDF and technical document translation engine that preserves complex layout structures, diagrams, and mathematical formulas, the visual aesthetic projects absolute fidelity, security, and effortless utility.

The personality balances **academic authority** with **high-velocity SaaS modernism**:
- **Target Audience:** Technical architects, patent attorneys, localization engineers, scientific researchers, and global enterprise operations teams who cannot tolerate compromised document layouts.
- **Emotional Response:** Inspires trust, calm certainty, and relief through immaculate structural order, legibility, and refined micro-interactions.
- **Design Movement:** Clean Modernism infused with low-contrast outline detailing and ambient slate elevation. Visual noise is stripped away; hierarchy is established strictly via deliberate typographic scale, calibrated slate-navy contrast, and surgical pops of vivid indigo.

## Colors

The palette relies on high-contrast informational neutrality anchored by deep slate-navy and pristine backgrounds, energized by a purposeful indigo accent system.

### Color Tokens & Roles

- **Canvas & Surfaces:**
  - `surface-canvas`: `#f8fafc` (Slate 50) – Subtle cool backdrop providing structure and separation for white surfaces.
  - `surface-elevated`: `#ffffff` – Pure white for cards, document visualizers, floating bars, and elevated panels.
  - `surface-subtle`: `#f1f5f9` (Slate 100) – For input fills, inactive badge containers, code blocks, and table headers.

- **Primary & Interactive:**
  - `primary`: `#4f46e5` (Indigo 600) – High-visibility primary action buttons, key indicators, and active states.
  - `primary-hover`: `#4338ca` (Indigo 700) – Hover and pressed states for primary triggers.
  - `primary-surface`: `#eef2ff` (Indigo 50) – Soft tinted backgrounds for active tabs, selected states, pill chips, and highlights.
  - `primary-border`: `#c7d2fe` (Indigo 200) – Accent borders on active input focus and highlighted pricing tiers.

- **Typography & Neutrals:**
  - `text-primary`: `#0f172a` (Slate 900) – High-authority headlines, document title bars, and core metrics.
  - `text-secondary`: `#334155` (Slate 700) – Long-form documentation, body copy, and secondary headers.
  - `text-tertiary`: `#64748b` (Slate 500) – Helper text, input placeholders, metadata, and breadcrumbs.
  - `border-subtle`: `#e2e8f0` (Slate 200) – Crisp, low-contrast structural borders for cards, dividers, and tables.
  - `border-strong`: `#cbd5e1` (Slate 300) – Interactive component borders, hover outlines, and checkboxes.

- **Feedback Accents:**
  - `success`: `#059669` / `success-surface`: `#ecfdf5` (Document verified, conversion complete).
  - `warning`: `#d97706` / `warning-surface`: `#fffbeb` (Layout parsing warning).
  - `error`: `#dc2626` / `error-surface`: `#fef2f2` (Upload format error).

## Typography

Typography is powered exclusively by **Plus Jakarta Sans** for a geometric, crisp, and humanized technical presentation.

### Usage Rules
- **Headline Display & H1:** Reserved for hero value propositions and main landing features. Must always be styled in `text-primary` (`#0f172a`) with negative tracking (`-0.025em` to `-0.03em`) to anchor technical authority.
- **Section Headers (H2/H3):** Use `headline-lg` and `headline-md`. Maintain generous line height to prevent ocular fatigue when paired with comparison diagrams.
- **Body Rhythm:** `body-lg` serves as the lead intro paragraph beneath display headers. `body-md` is standard for explanatory feature text, feature bullet points, and pricing tiers.
- **Badges & Micro-meta:** Utilize `label-caps` (all-caps styling) with increased tracking (`0.06em`) for categorical pill tags, file extension labels (`PDF`, `DOCX`, `LaTeX`), and status indicators.

## Layout & Spacing

The layout is architected around an open 12-column responsive fluid grid within a bounded maximum content width of `1280px` (`80rem`).

### Grid and Breakpoints
- **Desktop (1024px and up):** 12-column grid, `1.5rem` (`24px`) gutters, outer margin `2rem` (`32px`), container max-width `1280px`.
- **Tablet (640px – 1023px):** 8-column grid, `1.25rem` (`20px`) gutters, outer margin `1.5rem` (`24px`).
- **Mobile (< 640px):** 4-column grid, `1rem` (`16px`) gutters, outer margin `1rem` (`16px`).

### Vertical Rhythm
- **Hero & Primary Landing Sections:** Generous padding of `5rem` to `7rem` (80px–112px) between major landing page sections to ensure airiness and breathing space.
- **Card and Visualizer Spacing:** Internal component padding scales between `space-md` (16px) for compact widgets to `space-xl` (40px) for prominent before-and-after document comparison frames.

## Elevation & Depth

Visual depth is achieved through an interplay of **low-contrast outlines** paired with **soft, diffused ambient shadows** that keep surfaces crisp and modern.

### Elevation Levels

1. **Base / Flat Layer (`elevation-0`):**
   - Pure `#ffffff` or `#f8fafc` background with a crisp border: `1px solid #e2e8f0`.
   - Used for: Inset document viewers, data tables, and subtle container panels.

2. **Soft Card Elevation (`elevation-1`):**
   - Border: `1px solid #e2e8f0`
   - Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`
   - Used for: Feature cards, integration logos, and persistent toolbars.

3. **Interactive Hover & Dropdown Elevation (`elevation-2`):**
   - Border: `1px solid #cbd5e1`
   - Shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.05), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`
   - Used for: Hovered feature cards, upload zones during drag-and-drop, interactive language select popovers.

4. **Floating Display Overlay (`elevation-3`):**
   - Border: `1px solid rgba(226, 232, 240, 0.8)`
   - Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.07), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`
   - Used for: Interactive PDF preview modals, live split-pane comparison overlays, and sticky navigation headers.

## Shapes

The geometric structure relies on balanced, proportional roundedness (`level 2`) to deliver approachable software precision.

- **Base Corner Radius (`rounded-md`):** `0.5rem` (`8px`) – Applied to form fields, nested diagram previews, table containers, and buttons.
- **Large Radius (`rounded-lg`):** `1rem` (`16px`) – Applied to standard content cards, feature highlights, and dropzone wrappers.
- **Heroic Radius (`rounded-xl`):** `1.5rem` (`24px`) – Applied to main visual comparison containers and interactive demo windows.
- **Pill Badges (`rounded-full`):** `9999px` – Exclusively reserved for category badges, language pair tags (`EN → JP`), status badges, and subtle callout chips.

- **Primary Tint Style:** Background `#eef2ff`, border `1px solid #c7d2fe`, text `#4338ca`, font `label-caps`. Used for "Neural Layout Preservation", "CAD & Math Ready", and release tags.
- **Neutral Style:** Background `#f1f5f9`, border `1px solid #e2e8f0`, text `#334155`, font `label-md`. Used for page count and format chips (`.PDF`, `.XLSX`).

  - Right pane: Translated document retaining exact bounding boxes, font sizing, and visual orientation.
  - Divider: Interactive vertical slider handle in `#4f46e5` with a subtle white pill center for dragging.
  - Frame: Background `#ffffff`, border `1px solid #e2e8f0`, shadow `elevation-3`, rounded `1rem`.

### 4. Input Fields & File Dropzone
- **Text / Select Field:** Background `#ffffff`, border `1px solid #e2e8f0`, text `#0f172a`, placeholder `#64748b`, radius `0.5rem`, height `42px`, padding `0 14px`. Focus: border `#4f46e5`, ring `3px rgba(79, 70, 229, 0.12)`.
- **Upload Dropzone:** Dashed border `2px dashed #cbd5e1`, background `#f8fafc`, hover background `#eef2ff`, hover border `#4f46e5`. Centered upload cloud icon in `#4f46e5` with file specification hints in `body-sm`.

### 5. Cards & Comparison Grids
- **Feature Cards:** White background `#ffffff`, border `1px solid #e2e8f0`, radius `1rem`, padding `1.5rem`. Hover effect transitions subtle shadow to `elevation-2` with an accent stroke transition to `#c7d2fe`.
- **Header Structure:** Includes an icon encased in an `40x40px` soft-indigo square with rounded corners (`rounded-md`), followed by `headline-sm` and `body-md` descriptive copy.

### 6. Checkboxes & Radios
- Size `18px x 18px`, border `1.5px solid #cbd5e1`, radius `4px` (checkbox) or `9999px` (radio).
- Checked: Background `#4f46e5`, border `#4f46e5` with crisp white checkmark iconography. Focus: ring `3px rgba(79, 70, 229, 0.15)`.
